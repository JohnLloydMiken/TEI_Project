# Changelog

All notable changes to the TEI Bill Deposit Refund System are documented here.

## [May 11, 2026]

### Fixed
- Fixed customer properties configuration
- Fixed data export functionality
- Fixed tagging for BD (Bill Deposit) and pending statuses

### Changed
- Refactored customer table structure for better organization
- Updated Excel parser for improved data handling
- Added responsive design improvements for the overview dashboard
- Enhanced individual and batch checking logic
- Updated schema indexing for better query performance

### Added
- Added overview dashboard component
- Added responsive design for all dashboard views
- Improved layout of images and media display

### UI/UX Improvements
- Finished overview design (colors may still be subject to change)
- Improved dashboard layout responsiveness
- Reorganized customer table for clearer status tracking

## Previous Versions

### Earlier Features (v1.0)
- JWT-based authentication with role separation
- Admin upload functionality for customer lists
- Individual eligibility checker
- Batch eligibility check (paste and upload methods)
- Mark-as-claimed functionality
- Animated, responsive UI with Tailwind CSS
